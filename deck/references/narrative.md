# Narrative — deck structures & copy (ledes stripped)

Pick a structure for the brief (step 3, co-build), then write **assertion-style headlines** that carry each slide. No eyebrows, no ledes, no slide numbers — the headline does the work.

## Deck structures

| Structure | Slides | Use | Beat sequence |
|---|---|---|---|
| **Pitch / sales** | 7–10 | win a deal | Hook → their problem → cost of inaction → your solution → proof → differentiators → ROI → next step |
| **Client working session** | 8–16 | align + decide | Where we left off → the challenge → status → options → recommendation → decision → next steps |
| **Proposal** | 8–12 | get a yes | Context → problem → approach → plan/phases → proof → team → investment → the ask |
| **Talk / keynote** | 15–25 | move thinking | Hook → tension → idea → evidence → reframe → implication → call |
| **Report / readout** | 10–18 | inform | Thesis → method → findings (1 per slide) → so-what → recommendation |

**Duarte sparkline (any talk):** alternate *what is* (pain) ↔ *what could be* (better) → end on the new normal. Put the strongest contrast at the 1/3 and 2/3 marks.

## Headline patterns (assertion, not label)
A slide title is a **claim**, not a noun phrase. "Overview" → "The hand-off is where we lose half the funnel." Forms that work:
- Contrast: "[Old way] is over. [New way]." · "From [pain] to [gain]."
- Stakes: "Without [X], you lose [amount] every [period]."
- Result: "[Outcome] in [timeframe]."
- Proof: "[N] [companies] already [did the thing]."

## Copy formulas (for the body, kept tight)
- **PAS** (problem slides): pain → agitate → the fix.
- **Before–After–Bridge** (transformation / case study): where they are → where they'll be → your bridge.
- **FAB** (capabilities): feature → so you can → which means.
- **Cost of inaction** (urgency): status quo → what it's costing → it compounds.

## Density (from step 1, start light)
- **Speaker-led:** one idea per slide, big type, short phrases, more slides; lean on statement/quote/big-number/chapter beats. Pacing over density.
- **Reading-first:** more self-contained slides — grids, comparison tables, annotated diagrams, concise captions — but keep a strong hierarchy so it reads designed, not like a doc on a slide. If a dense slide overflows, split it; never shrink type to cram.

## Discipline (stop-slop)
- Only claims you can ground (these decks are sourced). If a number is shaky, say "estimate, to confirm."
- Cut anything that doesn't serve the desired action (the "delete test").
- Vary layouts — no 3 identical slides in a row; insert a chapter beat or big-number to reset attention every ~5–8 slides.
- Assertive business voice; no corporate filler, no hedging, no em-dash-itis.
